二维码生成器

紫人调查问卷 · 扫码传播工具

先将 survey.html 上传到免费托管平台（见下方说明），然后把得到的网址粘贴到这里。

📋 托管 + 生成完整步骤：
  1. 注册 GitHub 账号（免费）
  2. 创建新仓库，上传 survey.html 文件
  3. 进入仓库 Settings → Pages → Source 选 main 分支 → Save
  4. 等待1~2分钟，页面会显示一个网址如 https://用户名.github.io/仓库名/survey.html
  5. 把该网址粘贴到上方输入框，点击生成二维码
  6. 下载二维码图片，即可用于抖音传播

替代方案：Vercel / Netlify / Cloudflare Pages，均可免费托管，拖拽上传即可获得公网地址。
